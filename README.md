# Środowisko zajęć — Wprowadzenie do narzędzi biotechnologicznych

Rok akademicki 2026/2027. Organizacja: [upwr-bioinf](https://github.com/upwr-bioinf).

To repozytorium zawiera konfigurację maszyny wirtualnej / kontenera do zajęć.
Instrukcja uruchomienia jest w materiałach bloku 1 (`01_linux_i_git.md`, punkt B.1).

```bash
git clone https://github.com/upwr-bioinf/wnb2026-srodowisko.git
cd wnb2026-srodowisko
vagrant up
vagrant ssh
```

Wariant Docker: katalog `docker/`.
